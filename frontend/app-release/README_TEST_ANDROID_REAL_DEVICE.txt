TEST ANDROID SUR APPAREIL REEL
==============================

Adresse API configuree : http://192.168.11.100:3001

Fichier APK : app-release.apk

INSTALLATION
-----------
1. Transférez ce fichier sur votre téléphone Android.
2. Ouvrez le fichier APK.
3. Autorisez l'installation depuis une source inconnue si demandé.
4. Installez l'application.

PREREQUIS
---------
- Le backend doit être accessible depuis votre téléphone sur l'adresse :
  http://192.168.11.100:3001/api/health
- Assurez-vous que votre PC et votre téléphone sont sur le meme reseau Wi-Fi.
- Si le backend n'est pas accessible, vérifiez le firewall Windows et l'ordinateur.

En cas de problème, contactez-moi avec le message d'erreur affiché.
