INSTALLATION
============

1. Téléchargez le fichier "app-release.apk" sur votre téléphone.
2. Ouvrez le fichier APK.
3. Si Android demande : "Autoriser l'installation depuis une source inconnue" → Acceptez.
4. Appuyez sur "Installer".
5. Une fois terminé, appuyez sur "Ouvrir" pour lancer l'application.
