ERREUR ACTUELLE:
================
"Impossible de se connecter au serveur"
Serveur: https://afrijob-backend.onrender.com/api

CAUSE:
L'application a été compilée avec la configuration par défaut en production.
Le backend (Node.js) tourne localement sur VOTRE PC à 192.168.11.100:3001

SOLUTION ETAPE PAR ETAPE:
=========================

ETAPE 1: VERIFIER LA CONNECTIVITE
----------------------------------

A. Sur votre PC (le serveur):
   1. Ouvrez PowerShell
   2. Tapez: ipconfig
   3. Notez votre IP sous "IPv4 Address" (cherchez 192.168.x.x)
      Si vous ne voyez pas 192.168.11.100, votre IP est différente!
   
   4. Tapez: netstat -ano | Select-String "3001"
   5. Vous devriez voir: "TCP 0.0.0.0:3001 0.0.0.0:0 LISTENING"
      Si le backend n'écoute pas, relancez-le!

B. Sur votre téléphone (même Wi-Fi):
   1. Allez dans Paramètres > WiFi
   2. Cliquez sur votre réseau > Propriétés
   3. Notez l'IP du téléphone (ex: 192.168.11.50)
   4. Assurez-vous que PC et téléphone commencent par 192.168.11.x
      (Les 2 premiers octets DOIVENT être identiques!)

C. Test de connectivité téléphone → PC:
   1. Ouvrez un navigateur sur le téléphone
   2. Tapez: http://192.168.11.100:3001/
   3. Si vous voyez une page d'erreur ou une réponse, c'est BON!
   4. Si le page ne charge pas:
      - Le Wi-Fi n'est pas connecté au même réseau
      - Le firewall Windows bloque le port 3001
      - Le backend n'écoute pas

ETAPE 2: FIXER LE FIREWALL (si test de connectivité échoue)
------------------------------------------------------------

A. Ouvrir le Firewall Windows:
   1. Appuyez sur Win+R
   2. Tapez: wf.msc
   3. Cliquez OK

B. Créer une règle pour autoriser le port 3001:
   1. Cliquez "Règles de trafic entrant"
   2. Cliquez "Nouvelle règle..."
   3. Sélectionnez "Port" → Suivant
   4. Sélectionnez "TCP"
   5. Sélectionnez "Ports spécifiques" et tapez: 3001
   6. Sélectionnez "Autoriser la connexion" → Suivant
   7. Cochez tous les profils → Suivant
   8. Nom: "Allow Node.js Backend" → Terminer

C. Relancez le test de connectivité

ETAPE 3: INSTALLER ET TESTER L'APP
------------------------------------

A. Installation sur téléphone:
   1. Connectez le téléphone à l'ordinateur par USB
   2. Ouvrez PowerShell en tant qu'administrateur
   3. Tapez:
      adb install C:\Users\SYST\Desktop\Job_Research\frontend\app-release.apk
   4. Attendez le message "Success"

B. Lancer l'application:
   1. Ouvrez l'app "Mon Application Job" sur le téléphone
   2. Si elle affiche l'erreur de serveur:
      - Fermez l'app (balayez vers le haut)
      - Attendez 5 secondes
      - Relancez l'app
      - Cliquez "Réessayer"

C. Si ça marche toujours pas:
   - Allez au fichier FIX_ERREUR_CONNEXION.txt
