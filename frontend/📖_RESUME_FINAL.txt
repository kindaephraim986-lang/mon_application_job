POINTS IMPORTANTS A RETENIR:
============================

⚠️  RESEAU:
   1. PC ET TELEPHONE DOIVENT ETRE SUR LE MEME WI-FI
      → Les IPs doivent commencer par 192.168.11.x
   2. L'IP du PC DOIT ETRE 192.168.11.100
   3. Si différente, suivez le guide pour la corriger
   4. Le firewall Windows DOIT autoriser le port 3001

⚠️  ANDROID:
   1. Minimum Android 6.0
   2. Permissions: Internet, stockage, caméra
   3. Débogage USB doit être activé pour l'installation ADB

⚠️  BACKEND:
   1. Le serveur Node.js DOIT être en cours d'exécution
   2. Commande: node server.js (depuis le dossier backend)
   3. Vérification: netstat -ano | Select-String "3001"
   4. Vous devriez voir: "TCP 0.0.0.0:3001 ... LISTENING"

⚠️  AUTRES:
   1. Ne pas utiliser de VPN (bloque l'accès local)
   2. Wi-Fi 5GHz peut être instable → utilisez 2.4GHz
   3. Les comptes de test sont en français uniquement
